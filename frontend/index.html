Live Gallery Docs

Boxes

Add a box with the + button, choose the source type, paste a URL or ID, then Save. Use the box controls to edit, reload, solo audio, mute, expand, drag, or remove a box.

Presets

Use Preset to save the current layout, load saved layouts, export a JSON file, or import one again later.

Import Preset (Clipboard)

Copy preset JSON or a list of YouTube links, then choose Preset > Import Preset (Clipboard). Put one YouTube link per line. If a line starts with words followed by a space and then the YouTube link, those words become the box name.
