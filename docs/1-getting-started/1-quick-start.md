# Quick start

If Live Gallery is not installed yet, see [Download](../../README.md#download).

1. Click **+** to add a box, pick the source type, paste a URL or ID and save.
2. Repeat for each stream, or build the whole wall at once from a list of YouTube links ([Presets](../2-usage/2-presets.md)).
3. Solo a box with its headphones button, or let [Rotate audio](../2-usage/3-rotating-audio.md) move the sound for you.
4. Choose which alerts you want in **Settings**. The [Alerts](../3-reference/1-alerts.md) button lists what is wrong right now and the last five minutes.

Every box has a live audio meter with separate left and right levels, so a silent or one-sided feed stands out at a glance.
