# Keyboard shortcuts

On macOS use **Cmd** instead of **Ctrl**.

| Shortcut | Action                    |
| -------- | ------------------------- |
| Ctrl =   | Make boxes bigger         |
| Ctrl -   | Make boxes smaller        |
| Ctrl 0   | Reset box size to 100%    |
| Ctrl R   | Refresh the page          |
| F11      | Enter or exit full screen |
| Esc      | Close an expanded box     |
