# Presets

Save the current boxes as a named preset and load it later from the **Preset** menu, or export and import presets as JSON files.

## Build a wall from YouTube links

Copy a list of YouTube links and choose **Preset → Import Preset (Clipboard)**. Put one link per line. Words before a link become the box name:

```text
Morning Stream https://www.youtube.com/watch?v=dQw4w9WgXcQ
Backup Feed https://youtu.be/dQw4w9WgXcQ
https://www.youtube.com/live/dQw4w9WgXcQ
```

Importing replaces the current boxes, as does **New Preset**, which leaves a single empty box.
