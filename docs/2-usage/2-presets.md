# Presets

Save the current boxes as a named preset and load it later from the **Preset** menu, or export and import presets as JSON files. **Copy to Clipboard** copies the same JSON, so you can paste a wall into a chat and the other person loads it with **Import from Clipboard**.

## Build a wall from YouTube links

Copy a list of YouTube links and choose **Preset → Import from Clipboard**. Put one link per line. Words before a link become the box name:

```text
Morning Stream https://www.youtube.com/watch?v=dQw4w9WgXcQ
Backup Feed https://youtu.be/dQw4w9WgXcQ
https://www.youtube.com/live/dQw4w9WgXcQ
```

Loading or importing a preset replaces the current boxes, as does **New Preset**, which leaves a single empty box. Each can be undone with **Undo** for 8 s. The **Preset** button shows the name of the preset you loaded or saved last.
