# Rotating audio

**Rotate audio** moves the sound across boxes automatically, so you can hear each stream in turn without clicking.

Open the **Rotate** menu in the toolbar, turn on **Rotate audio**, enter the box numbers to include (for example `1 3 5-8`, where `5-8` means 5, 6, 7 and 8) and the seconds each box keeps the audio. The numbers are the ones shown in each box's header. The Rotate button is highlighted while rotation is on.

Rotation only changes which box is unmuted. Alerts keep running on every box.
